Предоставленные контакты и портфолио

`data/supplements.json` сейчас содержит `{}`. Основной CSV никогда не редактируется
ради новых материалов. При получении достоверных данных добавьте объект по
существующему id. Схема (пример структуры, не фактические контакты):

```json
{
  "ID_ИЗ_КАТАЛОГА": {
    "source": "Кто предоставил материалы и когда",
    "phone": null,
    "email": null,
    "messenger": null,
    "portfolio": []
  }
}
```

Для фото: src вида `/static/portfolio/name.jpg` (также png/jpeg/webp), alt,
caption, source, demonstration (true только для демонстрационного материала).
Файл должен существовать. Поле source обязательно, как и подпись/альтернативный
текст. Используйте материалы с разрешением владельца. После обновления — перезапуск.

Телефон, email, HTTPS-ссылки t.me или wa.me отображаются только при предоставлении.
Email-кнопка открывает mailto с черновиком, не отправляет письмо. Пользователь
проверяет и меняет текст в почтовом приложении. Сервис не подтверждает бронирование.

При отсутствии материалов показаны «Примеры работ пока не добавлены» и «Контакты
не предоставлены в демонстрационном датасете». Неверные дополнения не публикуются;
ошибка отображается, подробности пишутся в серверный журнал.
