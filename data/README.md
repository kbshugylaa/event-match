Исходный каталог

CSV/JSONL с 66 профилями не был предоставлен. Скопируйте настоящий файл в
`data/contractors.jsonl` или задайте `CATALOG_PATH` для CSV. Перезапустите сервер.
Данные не коммитятся по умолчанию; совместную публикацию согласуйте с владельцем.

Обязательные поля перечислены в `app/models.py`. UTF-8, для CSV допустим BOM.
Списки — JSON-массивы либо Python literal lists (без eval); разделитель CSV
определяется среди запятой, точки с запятой и табуляции. Булевы CSV: true/false/1/0.
`max_hours`: число > 0 или null (в CSV также пустая ячейка/None).
Цена — конечное число >= 0. Пустая description допустима, остальные строки обязательны.
busy_dates — полный список занятых дат YYYY-MM-DD в пределах 23.09–31.12.2026;
пустой список означает отсутствие занятых дат в этом календаре.
Загрузчик не может доказать полноту календаря: это обязательство источника.
Не подставляйте календарь из HTML-превью или количество дней.

Некорректный файл блокирует весь каталог; частичная молчаливая загрузка запрещена.
Несовпадение количества с 66 выдаёт явное предупреждение, не дополняет данные.
Тестовые записи находятся только в `tests/fixtures/` и не загружаются автоматически.
