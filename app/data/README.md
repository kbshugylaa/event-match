Предоставленный каталог

`contractors.csv` — побайтная копия `hackathon dataset anonymized .csv`,
предоставленного пользователем. Оригинал в Downloads не изменялся.

SHA-256: `6a724b6b7dfb5973343e68ba18dadb60fc807d87e3d78f03ee86fb26cb089f7d`.

Проверены: 66 уникальных id; 17 категорий; города Алматы, Астана, Зарубежье;
3 337 записей занятости; 13 synthetic; 8 city_imputed; 18 price_imputed;
9 профилей с max_hours=null. Даты в диапазоне 23.09–31.12.2026, повторов внутри
календарей нет. Имена и число занятых дней сверены со всеми 66 карточками HTML.

CSV UTF-8: разделитель столбцов — запятая, списков — `|`, булевы поля True/False,
пустой max_hours означает null. Загрузчик также принимает JSON-массивы и безопасные
Python literal lists через ast.literal_eval, без eval. Поддерживает CSV с BOM,
разделители столбцов `,`, `;`, табуляцию и JSONL.

Проверяются обязательные поля, уникальные id, типы, конечные неотрицательные цены,
списки без пустых/повторных значений, корректность календаря. Пустая description
допустима; пустые категории/форматы/языки отклоняются. Некорректный файл блокируется
целиком. Несовпадение количества с 66 выдаёт предупреждение, записи не добавляются.

Полнота календаря предполагается согласно документации источника; приложение
проверяет формат и диапазон, но не может подтвердить фактическую занятость подрядчика.
`synthetic=true` не означает, что профиль создала эта команда.

Контактов и файлов портфолио в источнике нет. Ссылки/названия внутри description
не превращаются в контакты автоматически. Дополнения хранятся в supplements.json.
