# Событие — подбор подрядчиков для мероприятий

Учебный веб-проект для хакатон-задачи **#79-lite**: каталог из **66 обезличенных профилей** подрядчиков и площадок с подбором до трёх рекомендаций по параметрам мероприятия.

Проект помогает организаторам свадеб, корпоративов и других событий сократить список кандидатов и посмотреть основания рекомендации. Это статическое клиентское приложение: вычисления выполняются в браузере, серверная обработка и аккаунт не нужны.

> Документация описывает фактический код текущей версии. Бюджет и формат сейчас влияют на баллы, но не являются строгими фильтрами. Это расхождение с постановкой хакатона и некоторыми подписями интерфейса; подробности приведены в ограничениях.

## 1. Что реализовано

- Форма заказа: город, дата, формат, категория, бюджет; дополнительно — длительность и язык работы подрядчика.
- Выдача максимум трёх анкет с ценой, городом, категориями, языками и пояснениями по шаблонам.
- Исключение занятых на выбранную дату кандидатов; фильтрация по выбранному языку и, с оговорками, длительности.
- Три состояния результата: найдены кандидаты; категории нет в городе; категория есть, но после фильтров кандидатов нет.
- Каталог всех 66 профилей с текстовым поиском и фильтрами города и категории.
- Подробная анкета в диалоговом окне: описание, цена, форматы, языки, длительность, число занятых дней и месяцы занятости.
- Пометки синтетических профилей и оценочных данных.
- Переключение интерфейса RU / KZ / EN. Исходные описания подрядчиков остаются на русском.
- Адаптивная сетка, дневная и ночная темы, альтернативная контрастная палитра и кнопки изменения масштаба текста. Есть подписи полей, ссылка перехода к содержимому, индикаторы фокуса и `aria-live` для результатов.
- Сохранение языка и настроек отображения в `localStorage`.
- Многофайловая версия и автономная копия в одном HTML-файле.

## 2. Как работает решение

1. Посетитель открывает страницу без регистрации и заполняет форму.
2. Браузер проверяет обязательные поля, числовые ограничения и дату в диапазоне **23.09.2026–31.12.2026**.
3. Функция `findMatches()` выбирает анкеты с точным совпадением города и категории. Если их нет, возвращает состояние `missing`.
4. Исключаются анкеты, у которых выбранная дата указана в `busy_dates`.
5. `scoreCandidate()` исключает несовпадающий выбранный язык. Для услуг, не относящихся к площадкам, проверяет указанный `max_hours`, если заказчик задал длительность. Для банкетных залов, загородных площадок, отелей и ресторанов эта проверка пропускается. Пустой лимит не исключает анкету.
6. Оставшимся кандидатам начисляются баллы. Если их нет, возвращается `empty`.
7. Анкеты сортируются по убыванию баллов, затем по возрастанию цены и ID. Показываются первые три. При одинаковых данных и параметрах порядок воспроизводим.
8. Пользователь читает пояснения и открывает подробную анкету. Обращение к исполнителю и бронирование не реализованы.

### Правила ранжирования

| Условие | Баллы / действие |
| --- | --- |
| Цена не превышает бюджет | +30; превышение бюджета не исключает анкету |
| Профиль принимает выбранный формат | +24; несовпадение не исключает анкету |
| Указан язык и он совпал | +18; несовпадение исключает анкету |
| Указана длительность и лимита достаточно | +12, если проверка применима |
| Указана длительность, но лимит отсутствует | +4 для услуг, не являющихся площадками |
| В описании найдена подстрока из списка для формата | +8 один раз |

Поиск в описании использует `includes()` для заранее заданных русских слов и фрагментов, например «корпорат», «бизнес», «форум». Эмбеддинги и языковые модели не используются. Пояснение состоит из первых двух сформированных причин, поэтому может не показывать все факторы итогового балла.

## 3. Технологии

| Компонент | Технология и назначение |
| --- | --- |
| Разметка | HTML5, формы, встроенная валидация, `<dialog>` |
| Оформление | CSS, Grid, Flexbox, media queries, CSS-переменные |
| Логика | JavaScript без прикладных фреймворков |
| Локализация | Собственный словарь `i18n.js`; браузерное форматирование дат и чисел |
| Настройки | Browser Web Storage API — `localStorage` |
| Данные | Локальный массив `window.PROFILES` в `data.js` |
| Шрифты | DM Sans и Manrope через Google Fonts; предусмотрены запасные шрифты |
| Генерация одного HTML | Node.js и встроенные модули `fs`, `path`, `vm`, `assert`; необязательна для запуска |
| Локальная раздача файлов | Стандартный HTTP-сервер Python 3; необязателен при прямом открытии HTML |

В приложении нет React/Vue, серверного фреймворка, базы данных, AI-модели, внешнего API подбора или платных API-ключей. Установка npm-зависимостей не требуется.

## 4. Архитектура проекта

Основная версия находится в `outputs`. Пути ниже указаны от корня рабочей папки:

```text
outputs/
├── README.md                 # Эта документация
├── index.html                # Разметка и подключение скриптов
├── styles.css                # Оформление, адаптивность и темы
├── data.js                   # 66 исходных профилей
├── i18n.js                   # Словари и объект window.SiteI18n
├── app.js                    # Подбор, каталог, анкеты и настройки
├── github-single/
│   ├── index.html            # HTML со встроенными стилями и скриптами
│   └── code-to-copy.txt      # Текстовая копия автономной версии
├── sobytie-full-code.zip     # Ранее подготовленный архив
└── sobytie-github-ready.zip  # Ранее подготовленный архив
work/
└── build-single.cjs          # Генератор автономной HTML-версии
```

`index.html` последовательно подключает `data.js`, `i18n.js` и `app.js` с атрибутом `defer`. `app.js` преобразует цену в число, а списки со знаком `|` — в массивы. Обработчики формы вызывают подбор и обновляют результаты; обработчики каталога открывают анкету в `<dialog>`. `SiteI18n` подставляет переводы при отрисовке и смене языка.

Локальный сервер только отдаёт файлы. Параметры подбора на сервер не отправляются. Настройки хранятся под ключами `eventPrefs` и `siteLanguage`; база пользователей или заявок не создаётся.

## 5. Установка и запуск

### Открытие готового файла

1. Сохраните папку `outputs` целиком, сохранив имена файлов.
2. Откройте `outputs/index.html` в современном браузере с поддержкой JavaScript, `localStorage` и `<dialog>`.
3. Если браузер ограничивает локальные файлы, используйте HTTP-сервер ниже.

Можно также открыть `outputs/github-single/index.html`: стили, данные и скрипты уже встроены в него, внешние шрифты в этой версии не подключаются.

### Локальный HTTP-сервер

Понадобится установленный Python 3. Откройте терминал **в корне проекта**:

```bash
python --version
python -m http.server 8000 --bind 127.0.0.1 --directory outputs
```

На Windows, если команда `python` отсутствует, но установлен Python Launcher:

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1 --directory outputs
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Для остановки нажмите `Ctrl+C`. Если терминал уже открыт внутри `outputs`, уберите параметр `--directory outputs`.

### Обновление автономной версии после правок

При наличии Node.js выполните из корня проекта:

```bash
node work/build-single.cjs
```

Скрипт перезаписывает оба файла в `outputs/github-single`, встраивает CSS и три JS-файла и убирает внешние шрифты. Он проверяет синтаксис встроенных скриптов, наличие 66 анкет и отсутствие внешних подключений стилей/скриптов. Это не проверка всей функциональности в браузере. ZIP-архивы этим скриптом не обновляются.

## 6. Как проверить решение жюри

Запустите многофайловую версию и выберите RU. Оставляйте длительность пустой и язык «Любой язык», кроме явно указанного случая. Вводите дату через календарь браузера.

> У бюджета сейчас стоят `min="1"` и `step="10000"`. Поэтому браузер принимает значения вида **1 + 10 000 × n**, например `2000001`, а ровно `2000000` может отклонить. Примеры учитывают это ограничение.

| Сценарий | Параметры формы | Ожидаемый результат текущей логики |
| --- | --- | --- |
| Плотная категория | Алматы; 15.10.2026; корпоратив; Ведущий; бюджет `2000001` | 8 кандидатов после фильтров, показаны 3: **Буллма → Джинбей → Мицури Канроджи** |
| Повтор запроса | Нажать «Найти варианты» ещё раз без изменений | Тот же порядок |
| Другая дата | В первом запросе изменить дату на 16.10.2026 | 5 кандидатов, показаны **Куррапика → Буллма → Мицури Канроджи** |
| Редкая категория | Алматы; 15.10.2026; свадьба; Флорист; бюджет `500001` | 2 анкеты: **Тихиро Огино → Тони Тони Чоппер** |
| Кандидаты есть, совпадений нет | Предыдущий запрос, но язык «Английский» и длительность `24` | «Нет подходящих совпадений»: 2 анкеты категории не проходят выбранный язык |
| Категории нет в городе | Зарубежье; 15.10.2026; корпоратив; Ведущий церемонии; бюджет `2000001` | «Категория не найдена» |

Числа и порядок в таблице получены вызовом существующих `findMatches()` и `scoreCandidate()` на текущем `data.js` при подготовке README. Проверка выполнялась отдельно от интерфейса; она не подтверждает браузерную отрисовку или доступность сайта. После изменения данных ожидаемые результаты нужно пересчитать.

Дополнительно в браузере:

1. Найдите в каталоге «Тони Тони Чоппер». Откройте анкету и посмотрите описание, форматы и пометку оценочной цены.
2. Переключите EN или KZ: подписи интерфейса меняются, описание подрядчика остаётся на русском.
3. Включите ночную тему и контрастную палитру, перезагрузите страницу: настройки должны сохраниться при доступном `localStorage`.
4. Проверьте известное ограничение: в первом запросе задайте бюджет `1`. Рекомендации всё равно будут выданы, поскольку превышение бюджета сейчас только лишает кандидата 30 баллов.

## 7. Данные и интеграции

Используется локальная копия обезличенного учебного набора в `data.js`. CSV/JSONL-первоисточник не включён в текущую папку проекта; загрузки и обновления набора по API нет.

В текущем массиве:

- **66** профилей и **17** уникальных категорий; одна анкета может иметь несколько категорий.
- **50** профилей Алматы, **15** Астаны и **1** с местоположением «Зарубежье».
- **13** записей с `synthetic=True`, **8** с `city_imputed=True`, **18** с `price_imputed=True`. Эти группы могут пересекаться.

| Поля | Назначение |
| --- | --- |
| `id`, `anon_name` | Идентификатор и обезличенное имя |
| `categories`, `city` | Категории и местоположение |
| `price_from_kzt` | Цена «от» в тенге |
| `event_formats`, `languages` | Форматы мероприятий и языки работы |
| `max_hours` | Лимит часов; пустое значение допускается |
| `busy_dates` | Занятые даты в формате `YYYY-MM-DD` |
| `description` | Исходное русскоязычное описание |
| `synthetic` | Признак синтетической анкеты |
| `city_imputed`, `price_imputed` | Признаки заполненных при подготовке набора города и цены |

В `data.js` исходные поля представлены строками; списки разделены `|`, флаги записаны как `"True"` / `"False"`. Для замены набора нужно редактировать этот файл, сохраняя структуру, и при необходимости пересобрать автономную версию.

Единственная обнаруженная внешняя интеграция основной страницы — Google Fonts. Контактов, реальных фотографий портфолио, отзывов и рейтингов в используемой структуре нет. Иллюстрации создаются CSS и символами и помечены как заглушки.

## 8. Ограничения текущей версии

1. **Бюджет и формат не являются строгими фильтрами.** Код начисляет баллы за совпадение, но не исключает неподходящую анкету. Часть текстов сайта обещает более строгую проверку, чем реализована.
2. **Валидация бюджета имеет смещение на 1 ₸** из-за сочетания `min="1"` и `step="10000"`.
3. **Объяснения ограничены первыми двумя причинами.** Они могут быть однотипными, не показывать причину итогового места и не объяснять, почему найдено меньше трёх анкет. Текст пустой выдачи перечисляет общие условия, а не точные причины отказа каждого кандидата.
4. **Календарь статичен.** Допустим только диапазон 23.09–31.12.2026; отсутствие даты в `busy_dates` трактуется как доступность по учебным данным. Подтверждения у подрядчика нет.
5. **Длительность проверяется не для всех категорий.** Для площадок проверка пропускается; пустой лимит допускает любую введённую длительность.
6. **Доступность реализована частично.** Большинство размеров текста заданы в `px`, поэтому изменение корневого масштаба кнопками A−/A+ не увеличивает весь интерфейс. При перезагрузке сохранённый масштаб дополнительно ограничивается диапазоном 0,9–1,2. Нет подтверждённого аудита WCAG или отдельных палитр для разных видов дальтонизма.
7. **Локализация не переводит исходные описания и поиск.** Поиск сопоставляет запрос с исходными русскоязычными полями; отсутствующие в словаре подписи сохраняются на исходном языке.
8. **Нет регистрации, авторизации, контактов, переписки, оплаты и бронирования.** Нет backend, базы данных, административной панели и синхронизации календарей.
9. **Работа зависит от JavaScript и браузерного хранилища.** Обработка всех ошибок доступа к `localStorage` не реализована.
10. **Нет подтверждённых замеров скорости и полной автоматизированной проверки интерфейса.** Наличие архивов не подтверждает актуальность их содержимого относительно исходных файлов.

## 9. Опубликованная версия

**Подтверждённая ссылка на deployed-версию в текущих файлах не найдена.** Папка `github-single` и архив с названием `github-ready` являются артефактами для переноса; они не подтверждают публикацию на GitHub Pages или другом хостинге. Для демонстрации используйте локальный запуск выше.
