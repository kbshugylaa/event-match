# Событие — умный подбор подрядчиков

Демонстрационный сайт для хакатон-задачи **#79-lite**. Он использует 66 строк из обезличенного CSV и по запросу показывает до трёх подходящих анкет с индивидуальными объяснениями. Здесь нет регистрации, бронирования и связи с исполнителями: это не предусмотрено постановкой задачи, а исходный набор не содержит контактов.

## Страницы и сценарий

Сайт сделан одной адаптивной страницей с тремя разделами:

1. **Подбор** — город, дата (23.09–31.12.2026), формат, категория, бюджет и необязательные длительность и язык.
2. **Как это работает** — этапы фильтрации и три явных исхода: варианты найдены, категории нет в городе, либо кандидаты есть, но ни один не прошёл условия.
3. **Все анкеты** — полный каталог с поиском и фильтрами. Карточка открывает профиль, форматы, языки, цену и число занятых дней.

Переключатель RU / KZ / EN находится в шапке рядом с настройками доступности. Выбранный язык сохраняется в браузере. Переведены интерфейс, фильтры, рекомендации и поля анкет; исходные описания подрядчиков приведены только на русском в CSV, поэтому они сохраняются на языке оригинала и помечаются в подробной анкете. Настройки шрифта, дневной/ночной темы и повышенной различимости цветов также доступны в шапке и сохраняются в браузере. Управление работает с клавиатуры.

## Запуск локально

1. Скачайте или распакуйте папку `outputs`.
2. Откройте `index.html` в современном браузере. Для локального показа этого достаточно.
3. Если браузер ограничивает локальные файлы, запустите сервер из этой папки:

   ```bash
   python -m http.server 8000
   ```

   Откройте [http://localhost:8000](http://localhost:8000).

Сайт не требует сборки, установки пакетов или API-ключей. Шрифт загружается из Google Fonts; при отсутствии интернета используются системные запасные шрифты.

## Логика подбора

Реализация находится в `app.js` и выполняется в браузере:

1. Строго отбираются профили по городу и категории. Если таких строк нет, возвращается исход «категории нет».
2. Исключаются профили, у которых дата есть в `busy_dates`.
3. Исключаются цена выше бюджета, несовпадающий формат, несовпадающий выбранный язык и недостаточный лимит часов.
4. Остаток детерминированно ранжируется по совпадению бюджета, формата, языка, длительности и ключевых слов описания. Равные результаты разрешаются ценой и затем ID.
5. Возвращаются первые три, у каждой карточки выводятся конкретные причины.

При пустой выдаче интерфейс перечисляет найденные причины фильтрации. Повтор запроса даёт тот же порядок. Это прозрачный rule-based baseline, а не обученная модель и не LLM; его можно объяснить и воспроизвести на защите.

## Данные и анкеты

- `data.js` — исходные 66 записей CSV, сериализованные как JavaScript-данные для работы без сервера.
- `index.html` — структура страницы и формы.
- `styles.css` — адаптивная стилизация, темы и режим повышенной различимости.
- `app.js` — фильтрация, ранжирование, объяснения, каталог и модальное окно анкеты.
- `i18n.js` — переводы интерфейса на русский, казахский и английский языки.

CSV содержит `synthetic`, `city_imputed` и `price_imputed`. Имена вымышлены/анонимизированы, и контактов и фото в наборе нет. Иллюстрации каталога — декоративные заглушки, не фотографии работ. Цены и занятость показаны только как значения учебного набора; заполненные при подготовке города и цены следует считать оценочными. Не используйте эти анкеты как настоящие публичные объявления.

## Примеры для ручной демонстрации

В форме выставляйте дату из разрешённого диапазона; занятость сильно зависит от конкретного дня:

- **Плотная категория:** Алматы → Ведущий → корпоратив → бюджет 2 000 000 ₸ → 15.10.2026.
- **Редкая категория:** Алматы → Флорист → свадьба → бюджет 500 000 ₸ → 15.10.2026.
- **Пустая выдача по условиям:** Алматы → Ведущий → свадьба → бюджет 1 ₸ → 15.10.2026.
- **Категории нет в городе:** Зарубежье → Ведущий церемонии → любой формат → бюджет 5 000 000 ₸ → 15.10.2026.
- **Проверка занятости:** сравните один и тот же запрос к ведущим Алматы на 15.10.2026 и 16.10.2026; состав и объяснение могут отличаться из-за busy_dates.

Фактическое количество совпадений зависит от дат в файле и дополнительных условий. Для гарантированного сценария занятости выберите две даты из календарей конкретных анкет и повторите те же остальные параметры.

## Как заменить или дополнить данные

Для демо замените `window.PROFILES` в `data.js` массивом объектов с полями `id`, `anon_name`, `categories`, `city`, `price_from_kzt`, `event_formats`, `languages`, `max_hours`, `busy_dates`, `description`, `synthetic`, `city_imputed`, `price_imputed`. Списки категорий/форматов/языков/дат записываются через `|`. После изменения перезагрузите страницу. В боевом проекте данные нужно валидировать на сервере и хранить в базе.

Чтобы показывать настоящие работы, получите согласие исполнителей и добавьте проверенные URL/файлы портфолио; декоративные заглушки в `styles.css` не следует выдавать за портфолио. Настоящую связь потребуют подтверждённые контакты и явная функция обращения.

## Развитие до полноценного сервиса

Добавить API и базу данных для профилей/календарей, безопасную регистрацию с хешированием паролей и восстановлением доступа, загрузку и модерацию фото, подтверждение контактных данных, серверную валидацию и защиту от злоупотреблений. Для надёжного бронирования понадобится атомарная проверка календаря; в текущей версии результат — только рекомендация.
